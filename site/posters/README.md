# 포스터 넣는 곳

아래 이름으로 그림 파일 넷을 이 폴더에 넣으면 로비 액자와 목록, 프로젝트 창에 걸립니다.
세로 2:3 비율(예: 1600×2400)입니다. 파일이 없는 자리는 빈 칸으로 남습니다.

| 액자(왼쪽부터) | 파일 |
|---|---|
| RONANLAB INFRA | `poster-infra.png` |
| FOREMAN | `poster-foreman.png` |
| PETMINT | `poster-petmint.png` |
| RUNSHOES | `poster-runshoes.png` |

저장소의 `posters/` 폴더에 있는 PNG 넷을 복사해 둔 것입니다. 포스터를 다시 만들면 여기에도 다시 복사합니다.
파일 이름을 바꾸고 싶으면 `js/config.js` 의 `poster` 값을 고칩니다.
