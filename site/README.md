# RONANLAB 포트폴리오 사이트

영화관 로비를 1인칭으로 걸어 다니는 포트폴리오입니다. 벽에 액자 넷이 걸려 있고,
가까이 가서 누르면 그 프로젝트 창이 열립니다. 지금은 로비와 걷기, 그리고 글이 들어갈 자리까지 있습니다.

## 로컬에서 띄우기

빌드 과정이 없습니다. 이 폴더를 정적 서버로 열기만 하면 됩니다.

```
cd site
python3 -m http.server
```

터미널에 찍히는 주소를 브라우저로 엽니다. 파일을 더블클릭해서 열면 모듈을 못 읽어 뜨지 않습니다.

주소 뒤에 붙이는 것들:

| 붙이는 것 | 하는 일 |
|---|---|
| `?view=list` | 3D 없이 목록 화면으로 엽니다 |
| `?slow=off` | 아무리 느려도 목록 화면으로 넘기지 않습니다. 화질만 낮춥니다 (`?view=3d` 도 같습니다) |
| `?quality=high` | 화질 단계를 고정합니다 (`high`, `low`, `min`). 느린 기기 판정을 하지 않습니다 |
| `?look=flip` | 끌어서 둘러보는 방향을 기본값의 반대로 써 봅니다 |
| `?enter` | 안내를 건너뛰고 바로 로비에 섭니다 |
| `?project=foreman` | 그 프로젝트 창을 연 채로 뜹니다 (`infra`, `foreman`, `petmint`, `runshoes`) |
| `?touch` | 데스크톱에서 휴대폰용 조이스틱 화면을 봅니다 |
| `?at=x,z,각도` | 로비 안 그 자리에서 시작합니다(살펴볼 때) |

## 조작

- 데스크톱: WASD 또는 방향키로 걷기, 마우스를 누른 채 끌어 둘러보기, Shift 로 달리기.
  포스터에 가까이 가서 마우스를 올리면 손가락 모양으로 바뀌고, 누르면 창이 열립니다. Enter 나 E 로도 열립니다.
- 휴대폰: 왼쪽 조이스틱으로 걷기, 오른쪽 조이스틱(또는 화면 끌기)으로 둘러보기.
  포스터 앞에 서면 「열기」 단추가 뜹니다. 포스터를 직접 눌러도 됩니다.
- 맨 위 메뉴(프로젝트, 소개, 연락처)는 어느 화면에서나 눌립니다.

## 나중에 넣을 것: 어디를 고치나

| 넣을 것 | 고칠 곳 |
|---|---|
| 포스터 그림 넷 | `posters/` 에 파일을 넣습니다. 이름은 `posters/README.md` 에 있습니다. 코드는 건드리지 않습니다 |
| 프로젝트 창 안의 글 | `js/config.js` 의 `PROJECTS` 에서 그 프로젝트의 `tagline`(한 줄), `body`(문단 배열) |
| 창의 단추 넷 주소 | `js/config.js` 의 `PROJECTS` 에서 `links` 의 `portfolio`, `docs`, `github`, `site`. 비워 두면 꺼진 단추로 보입니다 |
| 소개, 연락처 | `js/config.js` 의 `ABOUT`, `CONTACT` |
| 안내 문구, 알림 문구 | `js/config.js` 의 `TEXT` |
| 입간판과 네온 글 | `js/config.js` 의 `SIGN`. 입간판의 프로젝트 이름 넷은 `PROJECTS` 의 `title` 을 그대로 씁니다 |
| 프로젝트 차례, 이름 | `js/config.js` 의 `PROJECTS` 배열 순서와 `title`. 벽 왼쪽부터 이 순서로 걸립니다 |

## 어떤 파일을 고치면 무엇이 바뀌나

| 파일 | 바뀌는 것 |
|---|---|
| `js/config.js` | 글과 주소 전부(위 표) |
| `js/lobby.js` | 자판기에 든 물건 이름(`DRINKS`, `BOTTLES`, `SNACKS`, `BARS`), 매점 차림표의 품목과 값, 로비 생김새: 방 크기(`ROOM`), 액자 자리와 크기(`POSTER`), 조명 밝기, 샹들리에, 매표소와 직원, 매점 진열대, 자판기, 화분과 나무, 화장실 문, 깔개, 벨벳 줄, 입간판, 가운데 의자, 벽 램프, 걸어서 못 지나가는 곳 |
| `js/textures.js` | 그려서 쓰는 질감과 간판: 카펫 무늬, 깔개, 벽, 빈 액자, 이름판, 네온, 입간판, 화장실 표지판, 매점 차림표, 자판기 안의 캔과 봉지 그림 |
| `js/controls.js` | 걷는 빠르기(`WALK`, `RUN`), 눈높이(`EYE`), 마우스와 조이스틱 감도, 끌어서 둘러보는 방향(`LOOK`), 키 배치(`KEYMAP`) |
| `js/app3d.js` | 포스터가 눌리는 거리(`NEAR`), 빛 번짐 세기, 화질 단계, 느린 기기 판정 기준(`FPS_TO_LOW`, `FPS_TO_MIN`, `FPS_GIVE_UP`) |
| `js/ui.js` | 메뉴, 목록 카드, 소개와 연락처 판, 프로젝트 창이 만들어지는 방식 |
| `js/main.js` | 3D 와 목록 사이를 오가는 규칙, 주소 뒤에 붙이는 것들 |
| `css/style.css` | 메뉴 줄과 간판 로고, 안내, 목록, 창의 색과 크기. 맨 위 `:root` 에 색이 모여 있습니다 |
| `index.html` | 메뉴 항목, 안내 화면의 조작 설명 |

## 3D 가 안 될 때, 느릴 때

- WebGL2 가 없는 브라우저만 처음부터 목록 화면으로 엽니다.
- 화질은 세 단계입니다. `high`(카펫 반사, 빛 번짐, 조명 전부), `low`(그 셋 가운데 반사와 빛 번짐, 곁조명을 끔), `min`(해상도까지 절반).
  초당 20장 아래로 떨어지면 `low`, 12장 아래면 `min` 으로 내립니다.
- 그래픽카드 없이 CPU 로 그리는 브라우저는 `min` 에서 시작합니다. 로비에는 그대로 들어갑니다.
- 목록 화면으로 넘기는 것은 `min` 에서도 초당 2.5장이 안 나올 때뿐입니다. `?slow=off` 를 붙이면 그때도 넘기지 않습니다.
- 목록 화면 아래의 「3D 로비로 들어가기」 단추로 들어가면 그 뒤로는 느려도 다시 넘기지 않습니다.
- 그림자는 계산하지 않습니다(물건 밑 그림자는 그려 넣은 얼룩입니다). 무게는 조명 수, 카펫 반사, 빛 번짐에서 나옵니다.
- 서버에 그래픽카드가 있는데도 느리면 브라우저가 그것을 못 쓰는 것입니다. 크롬 주소창에 `chrome://gpu` 를 쳐서
  WebGL 이 "Software only" 로 나오는지 보고, 설정의 「하드웨어 가속 사용」을 켭니다. 원격 데스크톱 안의 브라우저는 대개 CPU 로 그립니다.
